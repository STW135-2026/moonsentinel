# MoonSentinel 项目申报书

## 一、基本信息

- 项目名称：MoonSentinel
- 项目副标题：用途绑定的 Arrow 隐私发布门禁
- 项目负责人：苏天纬
- 开源许可证：Apache-2.0
- 代码仓库：<https://github.com/STW135-2026/moonsentinel>

## 二、项目简介

MoonSentinel 是一个用 MoonBit 编写的 Arrow 数据隐私发布工具。它在数据交给研究团队、
合作方或公开发布前，检查这批数据能否用于本次用途，并按规则删除或替换敏感字段。

项目面向研究数据交付、合作方数据交换和 AI 训练样本准备等场景。它解决的不是数据格式
是否正确，而是数据在当前用途和接收方条件下能否安全发布。

## 三、核心功能

1. 检查发布用途和接收方是否在政策允许范围内；
2. 按行检查用户同意，未同意的数据进入隔离结果；
3. 使用 k-匿名和 l-diversity 检查小群体识别风险；
4. 默认不发布未配置的列，直接标识符只能删除，敏感文本可以替换；
5. 输出可发布数据、隔离数据、拒绝原因和发布清单四类 Arrow 数据。

## 四、使用方式

调用方传入 `RecordBatch`、隐私政策和发布请求，MoonSentinel 返回本次发布结果。未授权的
用途或接收方会导致整批拒绝；部分行不满足同意或匿名要求时，只隔离这些行，其余行仍可
按政策发布。仓库提供了可直接运行的反欺诈研究示例。

## 五、项目差异

MoonSentinel 不做通用数据质量检查，也不提供 CSV/JSONL 合同校验、画像、质量评分或合同
diff。与 MoonVerity 相比，本项目关注用途授权、接收方限制、逐行同意、匿名性、敏感字段
处置和发布留痕。两者可以串联使用：先检查数据质量，再决定数据能否离开当前信任边界。

更完整的边界说明见
[差异化文档](https://github.com/STW135-2026/moonsentinel/blob/main/docs/DIFFERENTIATION.zh-CN.md)。

## 六、实现与原创边界

项目使用 `shunge/arrow@0.1.0` 处理 Arrow 数据；隐私政策、发布请求、用途与接收方授权、
同意检查、k-匿名、l-diversity、列级处置、发布清单、测试和演示均由本项目实现。

## 七、当前成果与验收

- 已完成核心库、测试和可运行示例；
- Native、JavaScript、Wasm、Wasm-GC 四个目标使用同一套规则；
- 未授权请求会被拒绝，不合格行会被隔离；
- 发布结果不包含直接标识符，敏感字段按政策处理；
- 发布清单记录请求编号、用途、接收方、处理结果和发布列；
- 项目通过 `moon fmt --check`、`moon check --target all --deny-warn` 和
  `moon test --target all --deny-warn` 验证。

项目架构、演示步骤和完整测试说明见仓库 README 与 `docs/` 目录。
